# 07: Control de Transferencias

**What to build:** El Miembro puede cancelar, reintentar, lanzar varias Transferencias a la vez y reanudar una interrumpida por un corte de red.

**Blocked by:** 06-subir-y-descargar-con-cola-de-transferencias

**Status:** ready-for-agent

- [ ] Cancelar una Transferencia en curso
- [ ] Reintentar una fallida
- [ ] Varias Transferencias en paralelo
- [ ] Una Transferencia cortada se reanuda donde se quedó, verificado contra el banco de pruebas
- [ ] Si la reanudación resulta demasiado costosa, se documenta y se deja fuera con el acuerdo del usuario
