# Proyecto genérico con branding fijado en compilación

El proyecto se llama `sshpanel` y no contiene ningún valor de una instancia concreta (host, usuarios, huellas, claves). Nombre, identificador, extensión del Perfil, icono y color de acento viven en `branding.toml`, que un script vuelca en la configuración de Tauri; el valor por defecto es neutro, "SSH Panel" con la extensión `.sshpanel`, y es el que publican las Releases de este repositorio. La extensión no puede cambiarse en runtime porque el sistema operativo la asocia a la app al instalar, así que cada instancia es un fork que edita `branding.toml`, con su propio identificador, y publica sus propias Releases; el actualizador exige además sus propias claves de firma y repositorio de releases.
