# Tauri como framework de UI

Usamos Tauri (frontend web en TypeScript, backend en Rust con SSH/SFTP) en lugar de una GUI en Rust puro (Slint, egui, Dioxus). Es la opción que da mejor aspecto moderno, drag & drop nativo sencillo y una terminal embebida madura (xterm.js), a costa de binarios más pesados y de mantener dos lenguajes.
